# Sistema de Administración de Estacionamiento Inteligente

**Curso:** Programación II
**Lenguaje:** C++

## Descripción
Sistema desarrollado para gestionar el ingreso, salida y estacionamiento de vehículos, utilizando estructuras dinámicas (Listas enlazadas simple, doble y circular, y Matriz dinámica), iteradores propios y manejo de excepciones.

## Compilación
g++ src/*.cpp -I include -o app
./app
